# v0.1.6

- 원격 화면 전체 화면 보기 및 F11/버튼으로 복귀
- 관리자 화면을 대상 PC에 공유: 일반 창 / 집중 모드
- 양쪽 화면 캡처에 실제 마우스 커서 합성
- Windows 키와 조합키를 원격 화면에 초점이 있을 때만 대상에 전달
- 1280px·JPEG 55·약 80ms 간격, 화면 표시 확인 및 최신 프레임 처리로 지연 누적 제한
- 대상에서 확인·선택한 폴더로 파일 전송, 관리자에서도 받은 파일의 저장 폴더 선택
- 화면을 가리는 잠금과 마우스·키보드 잠금 ON/OFF. 연결 종료·응답 시간 초과·긴급 해제 시 풀림
- 종료·재시작 요청은 60초 유예 없이 실행. 저장하지 않은 작업을 강제로 종료하는 /f 옵션은 사용하지 않음

양쪽 프로그램을 업데이트하세요. 최초 등록 허용·긴급 해제·대상에서 프로그램 종료는 유지됩니다.
파일 받기는 대상이 직접 선택한 파일을 복사합니다. 대상의 파일을 강제로 읽는 기능은 없습니다.
집중 모드와 화면 잠금은 일반 데스크톱 창으로 구현되며 Windows 보안 화면을 차단하지 않습니다.
