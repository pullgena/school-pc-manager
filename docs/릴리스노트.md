# v0.1.5

- 관리자·관리 대상 각각 Windows x64 설치 프로그램을 제공합니다.
- 사용자 설치 폴더에 EXE, 제거 프로그램, 사용방법을 설치합니다.
- 관리 대상의 X 버튼·최소화는 트레이로 숨깁니다. 트레이에서 열기·긴급 해제·종료가 가능합니다.
- 설치 시 관리 대상의 Windows 로그인 자동 실행을 기본 선택합니다. 자동 실행 시 연결 대기를 시작합니다.
- 첫 연결 승인에서 등록 관리자의 이후 연결·전원 요청 자동 허용을 선택할 수 있습니다. 설정에서 미리 허용하거나 취소할 수도 있습니다.
- 등록 키 변경 시 자동 허용도 취소됩니다. 잘못된 등록 키는 자동 허용 상태에서도 거절됩니다.
- 연결·제어 표시, 긴급 해제, 입력 잠금 시간 제한은 유지합니다. 긴급 해제 시 연결 대기도 종료합니다.
- 앱 업데이트와 설치 프로그램 재설치 모두 설치 EXE 옆에 `.previous` 백업을 남깁니다.
- Windows 앱 목록과 프로그램 설정에서 설치형 프로그램 제거를 지원합니다.

자동 실행은 현재 사용자 Windows 로그인 후에 실행됩니다. 로그인 전 서비스나 숨겨진 실행은 아닙니다.
종료·재시작은 60초 유예 후 실행합니다. 파일 보내기는 계속 대상에서 직접 선택합니다.
