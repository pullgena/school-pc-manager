v0.1.3 노트북 전원 기능

- PC 설정의 전원 켜기 (Wake-on-LAN): 등록된 MAC에 로컬 브로드캐스트 매직 패킷 전송
- 연결된 PC 탭의 전원 메뉴: 재시작·전원 끄기 요청
- 대상 프로그램의 등록 파일에 해당 주소의 어댑터 MAC 자동 포함
- 이전 등록 파일 호환, 관리자에서 MAC 직접 수정

켜기 신호 전송은 실제 부팅 성공을 의미하지 않습니다. WOL 지원 하드웨어·BIOS 설정·전원 공급이 필요합니다.
Wi-Fi 및 완전 종료에서의 켜기는 노트북 모델과 전원 상태에 따라 지원되지 않습니다.
종료·재시작은 대상에서 승인한 뒤 60초 유예를 두고 수행됩니다.
