v0.1.1 연결·삭제 기능

- 저장된 PC 목록 클릭 연결, 전체 원클릭 연결과 종료
- 끊어진 PC 탭 재연결
- PC 등록과 연결 키 삭제 확인
- Windows Wi-Fi 연결 해제, 저장 Wi-Fi 정보 삭제, 인터넷 설정 열기
- 대상 PC의 Wi-Fi 관리 창 열기 요청
- 현재 프로그램과 해당 역할의 설정·로그·백업 제거
- TLS 승인 완료 후에만 연결된 상태로 표시

Wi-Fi 저장 정보 삭제와 프로그램 제거는 대상과 내용을 표시한 후 확인합니다.
학교 정책 Wi-Fi는 삭제하지 않습니다. 프로그램 제거는 받은 파일과 다른 역할의 프로그램을 유지합니다.
접속 시 대상 PC 승인과 긴급 해제 기능은 유지합니다.
