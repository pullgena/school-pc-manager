# v0.1.9

- 대상 프로그램의 일반 종료 메뉴와 트레이 종료는 연결된 관리자에게 승인을 요청하며, 승인된 요청만 종료
- 거절·응답 시간 초과·연결 장애 때 종료 요청은 취소. 관리자가 연결되어 있지 않으면 로컬 종료 가능
- 관리자에 PC별/전체 긴급 제어 중지 버튼 추가. 연결 종료와 함께 공유·입력·잠금 해제
- 대상의 Ctrl+Alt+F12 및 긴급 해제 메뉴는 유지
- 내 화면 공유에서 모니터 이름·해상도·미리보기를 확인하고 공유할 모니터 선택. 일반/집중 모드 모두 적용
- 선택한 모니터가 사라지면 공유를 중단하고 다시 선택하도록 안내

양쪽 프로그램을 v0.1.9로 업데이트하세요. Windows 종료·로그아웃과 긴급 해제는 관리자 승인을 기다리지 않습니다.

- 마우스 잠금·집중 모드·원격 입력 차단 때만 마우스 훅 설치, 잠금 해제·연결 종료·시간 만료 때 제거

- 클릭 위치와 버튼 동작을 한 작업으로 전송하여 빠른 클릭의 누름/떼기 순서 보장
- 원격 화면의 초점 상실·캡처 해제·원격 입력 OFF 때 남은 이동 취소와 버튼 해제
- 화면 바깥으로 드래그할 때 가장자리 좌표로 이동하고 마지막 위치에서 버튼 해제

관리자와 관리 대상 프로그램을 함께 업데이트하세요. 화면 전송 속도는 네트워크와 PC 성능에 따라 달라집니다.

파일 받기는 대상이 직접 선택한 파일을 복사합니다. 대상의 파일을 강제로 읽는 기능은 없습니다.
집중 모드와 화면 잠금은 일반 데스크톱 창으로 구현되며 Windows 보안 화면을 차단하지 않습니다.

### 영문 입력·대상 입력 차단·수신 위치

- 영문·숫자·기호는 문자로 전달해 대상 PC의 한/영 상태와 관계없이 입력합니다. 원격 입력을 켜고 대상의 입력 칸을 클릭하세요. 대상의 한글 IME를 사용할 때는 **더 보기 → 영문·문자 직접 입력**을 끄세요. Ctrl/Alt 단축키와 이동 키는 키 입력으로 전달됩니다.
- **원격 입력 중 대상 입력 차단**을 선택하면 원격 입력이 켜진 동안 대상의 물리 마우스·키보드를 차단합니다. 선택하지 않으면 함께 조작할 수 있습니다. 원격 입력을 끄면 이 옵션의 차단만 풀리고, 별도로 설정한 잠금은 유지됩니다. 긴급 해제와 연결 종료 시에는 모두 해제됩니다.
- **파일 → 받은 파일 저장 위치…**에서 PC별 수신 폴더를 지정하세요. 다음 연결에서도 유지되고, 대상이 직접 제출한 파일과 파일 받기 요청으로 선택한 파일 모두 이 폴더에 복사됩니다. 파일 받기 요청에서 새 폴더를 고르면 이후 제출 파일에도 적용됩니다. 저장 위치를 지정하지 않으면 기존 Downloads 아래 받은 파일 폴더를 사용합니다.
