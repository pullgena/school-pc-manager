# School PC Manager 사용방법

## 1. 프로그램 준비

최신 릴리스에서 `SchoolPc.Admin.Setup.exe`, `SchoolPc.Agent.Setup.exe`를 받습니다.
관리자 PC에는 Admin Setup, 관리할 PC에는 Agent Setup으로 설치합니다.
Windows x64용이며 런타임이 포함되어 있습니다. 설치 후 시작 메뉴에서 실행하세요.
대상 설치의 Windows 로그인 시 자동 실행은 기본 선택됩니다.

## 2. 대상 PC 등록

대상 프로그램에서 PC 이름을 `교실 01`처럼 정합니다.
**연결 주소**에는 관리자 PC가 접근할 수 있는 대상 PC의 IPv4 주소를 넣습니다.
자동 입력된 주소가 VPN·가상 어댑터 주소라면 Wi-Fi/유선 LAN의 주소로 수정하세요.
대상에서 Windows 설정 → 네트워크 및 인터넷 → 연결 속성을 열어 IPv4 주소를 확인할 수 있습니다.

**관리자 등록 파일 저장**을 눌러 `pc-registration.json`을 만듭니다.
파일에는 PC 이름, 주소, 포트, 인증서 지문, 접근 키가 들어 있습니다.
이 파일을 USB 등으로 관리자에게 전달합니다. 공개 저장소나 공개 채팅에 올리지 마세요.
PC마다 등록 파일을 따로 만듭니다. 대상에서 **등록 키 변경**을 누르면 이전 등록 파일은 무효가 됩니다.

## 3. 연결

대상 프로그램에서 **연결 대기 시작**을 누릅니다.
Windows 방화벽에서 사설 네트워크 통신을 허용합니다. 기본 포트는 TCP 45832입니다.
학교 방화벽이나 무선망의 PC 간 통신 차단 정책이 있으면 네트워크 담당자가 허용해야 연결됩니다.

관리자 프로그램에서 **등록 파일 가져오기**로 파일을 선택합니다. 여러 파일을 동시에 가져올 수 있습니다.
왼쪽에서 PC를 선택하고 **선택한 PC 연결**을 누릅니다.
대상 PC에서 나타나는 승인 창의 **이 연결 허용**을 누릅니다. 30초 안에 누르지 않으면 거절됩니다.
IP 주소가 달라지면 관리자 창 왼쪽의 주소를 고치고 **주소 저장**을 누른 뒤 탭을 닫고 다시 연결하세요.

## 4. 화면 공유·화면 제어

연결된 PC의 탭에서 **화면 보기**를 체크하면 기본 모니터 화면을 볼 수 있습니다.
**원격 입력**을 체크하고 원격 화면을 클릭하면 마우스와 키보드 입력을 전달합니다.
다른 버튼이나 탭을 선택하면 눌려 있던 원격 키와 마우스 버튼을 해제합니다.
한글 입력은 대상 PC의 한/영·IME 설정을 따릅니다.
UAC 보안 화면이나 Windows 로그인 화면은 원격 제어할 수 없습니다.
현재 공유는 약 3FPS이므로 일반 수업 지원용이며 영상·게임 스트리밍용으로는 적합하지 않습니다.

## 5. 파일 전송

관리자: **파일 보내기** → 파일 선택. 최대 256MB입니다.
대상: **관리자에게 파일 보내기** → 파일을 직접 선택합니다.
관리자의 **파일 받기 요청**은 대상에 파일 선택 창을 띄웁니다. 대상이 선택해야 파일이 전송됩니다.

파일은 `다운로드\SchoolPc 받은 파일`에 저장됩니다.
관리자 PC에서는 그 아래 대상 PC 이름 폴더에 저장됩니다.
동명 파일을 덮어쓰지 않도록 파일명에 전송 ID 일부를 붙입니다.
받은 파일을 자동 실행하지 않습니다. 해시가 다르거나 전송이 끊기면 미완료 파일은 제거합니다.

## 6. 입력 잠금·컴퓨터 잠금

관리자 탭에서 **마우스 잠금**, **키보드 잠금**을 선택하고 초를 정한 뒤 **잠금 적용**을 누릅니다.
대상의 물리 입력만 제한하며 원격 입력은 계속 사용할 수 있습니다.
시간을 지정하지 않고 ON/OFF로 제어합니다. 연결이 끊기거나 15초 동안 연결 확인 응답이 없으면 해제됩니다.
**입력 잠금 해제**는 현재 PC, **전체 입력 잠금 해제**는 연결된 모든 PC에 적용합니다.

대상의 **설정 탭 → 긴급 제어 해제** 또는 설정한 단축키(기본 **Ctrl+Alt+F12**)를 사용하면 현재 연결과 대기를 종료하고 모든 잠금을 풉니다.
Windows **Ctrl+Alt+Del** 보안 화면도 차단하지 않습니다.

**Windows 잠금**은 대상 PC를 로그인 화면으로 잠급니다. 대상에서 직접 로그인해야 해제됩니다.
**다시 시작 요청**, **종료 요청**은 자동 허용 상태이면 추가 승인 없이 즉시 실행됩니다. 자동 허용이 꺼져 있으면 대상에서 승인합니다.
예약된 종료를 취소하려면 대상에서 Windows 실행(Win+R)에 `shutdown /a`를 입력합니다.

## 7. 업데이트

양쪽 프로그램의 **업데이트 확인**을 누릅니다.
새 정식 릴리스가 있으면 변경 내용을 보여 주고 설치 여부를 묻습니다.
동의하면 다운로드, SHA-256 검사, 연결 종료, 실행 파일 교체, 재실행 순으로 처리합니다.
Windows 사용자 설정과 등록 정보는 유지합니다.
`SchoolPc.Admin.exe`와 `SchoolPc.Agent.exe` 파일명은 바꾸지 마세요.
쓰기 권한이 없는 폴더이면 업데이트가 실패하므로 사용자 폴더로 이동하세요.
문제가 생기면 실행 파일 옆의 `.previous` 백업을 원래 이름으로 복사해 사용할 수 있습니다.

## 8. 연결이 안 될 때

- Agent가 실행 중이고 **연결 대기 중**인지 확인합니다.
- PC 주소와 포트가 현재 대상 PC와 일치하는지 확인합니다.
- Windows 방화벽에서 사설망 TCP 45832를 허용했는지 확인합니다.
- 관리자와 대상이 같은 학교 네트워크에 있는지 확인합니다.
- 등록 키를 변경했다면 새 등록 파일을 다시 가져옵니다.
- 이미 다른 관리자가 연결되어 있으면 그 연결을 종료합니다.
- 접속 승인 창에서 30초 안에 승인했는지 확인합니다.
- VPN·서로 다른 VLAN·무선 AP 격리 설정은 네트워크 담당자에게 확인합니다.

설치 시 자동 실행을 선택하면 Windows 로그인 후 트레이에서 실행됩니다. X 버튼은 트레이로 숨깁니다. 실제 종료는 트레이의 프로그램 종료를 사용합니다.

## 9. 한 번 클릭으로 연결·종료

등록 파일을 처음 한 번 가져온 뒤 **목록 클릭으로 바로 연결**을 체크하세요.
이후 왼쪽 PC 이름을 한 번 클릭하면 연결합니다. 최초 승인 후 자동 허용을 선택하면 이후 접속 승인은 생략됩니다.
이미 연결된 PC를 클릭하면 해당 탭으로 이동합니다. 수동으로 연결을 끊은 PC는 목록 클릭으로 재접속하지 않습니다. 다시 접속하려면 **선택한 PC 연결** 또는 **모두 연결**을 누르세요. 목록의 빈 공간을 클릭하면 연결하지 않습니다.
전체 연결은 **한 번에 모두 연결**, 전체 원격 연결 해제는 **모든 연결 종료**를 사용합니다.

## 10. 세 가지 삭제

1. **PC 등록 삭제**: 왼쪽에서 PC를 선택하고 삭제를 누릅니다. 현재 연결을 종료하고 관리자에 저장된 그 PC의 등록과 연결 키를 지웁니다.
2. **Windows Wi-Fi 관리**: 저장된 Wi-Fi를 선택하고 **선택한 Wi-Fi 저장 정보 삭제**를 누릅니다. 삭제 대상과 비밀번호 재입력 필요 여부를 안내한 뒤 확인합니다. 인터넷 연결 해제는 위쪽에서 Wi-Fi 어댑터를 선택하고 **Wi-Fi 연결 해제**를 누릅니다. 학교 정책 프로필은 여기서 삭제하지 않습니다.
3. **현재 프로그램 제거**: 현재 역할의 프로그램을 종료한 뒤 EXE, 이전 버전 백업, 해당 역할의 등록/인증 설정과 로그를 제거합니다. 받았던 파일·다른 역할의 프로그램·Wi-Fi 정보는 지우지 않습니다. 임시 제거 도우미와 내려받은 ZIP, 전달용 등록 파일은 별도로 삭제할 수 있습니다.

대상 PC의 Wi-Fi 관리 창을 열려면 연결된 탭의 **대상 Wi-Fi 관리 요청**을 누릅니다.
인터넷 연결 해제와 Wi-Fi 저장 정보 삭제는 서로 다른 작업입니다.
Windows 인터넷 설정 자체를 삭제하지 않으며, 유선 어댑터·드라이버·VPN·방화벽 설정을 자동 제거하지 않습니다.

## 11. v0.1.2 간단한 화면

관리자: **PC 추가** 후 목록에서 PC를 클릭합니다. 대상의 승인이 끝나면 화면이 자동 표시됩니다. **원격 입력**을 켜면 제어할 수 있습니다.
파일 전송은 **파일**, 입력/Windows 잠금은 **잠금**, 메시지·전원·대상 Wi-Fi는 **더 보기**에 있습니다.
주소 변경과 등록 삭제는 **PC 설정**, 내 Wi-Fi·업데이트·프로그램 제거는 상단 **설정**에 있습니다.
관리 대상: **연결 탭**에서 연결 시작·등록 파일 저장을 사용합니다. 긴급 해제·단축키 변경·확인은 **설정 탭**에 있습니다. 연결 정보·파일·Wi-Fi·업데이트·제거는 **설정 탭 → 기타 설정**에 있습니다. 활동 내역은 **활동 내역 보기**를 눌러 표시합니다.

## v0.1.3 노트북 전원

- **켜기**: 관리자 목록에서 PC를 선택 → **PC 설정 → 전원 켜기 (WOL)**. 연결되어 있지 않아도 저장된 MAC 주소로 로컬 네트워크에 신호를 보냅니다. 신호 전송 성공을 실제 켜짐 성공으로 표시하지 않습니다.
- **끄기·재시작**: 연결된 PC의 탭 → **전원 → 전원 끄기 / 재시작**. 자동 허용 상태이면 추가 승인 없이 즉시 실행합니다. 그 외에는 대상 승인 후 실행합니다.
- 새 대상 프로그램에서 등록 파일을 다시 저장하면 연결 주소와 일치하는 네트워크 어댑터의 MAC을 포함합니다. 이전 등록 파일에는 MAC이 없으므로 **PC 설정 → 주소·포트·MAC 변경**에서 직접 입력할 수도 있습니다.
- 꺼진 노트북을 켜려면 해당 모델의 BIOS/UEFI와 네트워크 장치가 WOL 및 해당 전원 상태에서의 깨우기를 지원해야 합니다. 유선 LAN과 Wi-Fi의 지원은 다릅니다. 노트북 제조사의 안내를 확인하세요.
- 같은 로컬 네트워크에서 사용하며 인터넷 중계·라우터 포트 개방·BIOS/드라이버 자동 변경은 수행하지 않습니다. 전원 공급이 끊긴 기기는 켤 수 없습니다.
- 설치 시 자동 실행을 선택하면 Windows 로그인 후 대상 프로그램이 실행됩니다. Windows 자동 로그인 기능은 포함하지 않습니다.

참고: [Microsoft WOL 동작](https://learn.microsoft.com/en-us/troubleshoot/windows-client/deployment/wake-on-lan-feature), [시스템 전원 상태](https://learn.microsoft.com/en-us/windows/win32/power/system-power-states).


## v0.1.5 설치·트레이·자동 허용

- 관리자 노트북: `SchoolPc.Admin.Setup.exe`를 설치합니다.
- 관리 대상 노트북: `SchoolPc.Agent.Setup.exe`를 설치합니다. **Windows 로그인 시 자동 실행**은 기본 선택됩니다.
- 기본 설치 경로: `%LOCALAPPDATA%\Programs\SchoolPcManager\Admin` 또는 `Agent`. 각 역할의 설치 위치는 따로 선택할 수 있습니다.
- 기존 휴대용 EXE는 종료하고 설치 프로그램을 실행하세요. 같은 Windows 사용자이면 기존 PC 등록·설정은 유지됩니다. 두 사본을 동시에 실행하지 마세요.
- 대상 프로그램은 실행하면 연결 대기를 시작합니다. X 버튼과 최소화는 트레이로 숨깁니다. 숨겨도 연결은 유지됩니다.
- 트레이 아이콘을 두 번 클릭하면 창을 열 수 있습니다. 트레이 메뉴에서는 창 열기와 프로그램 종료를 선택합니다. 긴급 해제는 프로그램의 **설정 탭**에서 사용합니다.
- 첫 연결 승인에서 **이 등록 키를 가진 관리자의 다음 연결·전원 요청 자동 허용**을 체크하고 허용하세요. 이후 동일한 등록 키의 요청에는 승인 창이 없습니다.
- 대상 **설정 → 등록 관리자 자동 허용 설정**에서 처음부터 허용하거나 취소할 수 있습니다. 등록 파일·키는 신뢰하는 관리자에게만 전달하세요.
- 대상 **설정 탭 → Windows 로그인 시 자동 실행 체크박스**에서 자동 실행을 변경할 수 있습니다. 로그인 전 원격 제어는 지원하지 않습니다.
- **Ctrl+Alt+F12**는 현재 연결과 연결 대기를 종료합니다. 다시 사용하려면 대상에서 연결 대기를 시작하세요.
- **업데이트 확인**으로 업데이트하면 설치 경로의 `SchoolPc.Admin.exe.previous` / `SchoolPc.Agent.exe.previous`에 직전 EXE가 저장됩니다. 새 설치 프로그램으로 덮어 설치해도 같은 위치에 백업합니다.
- 시작 메뉴와 Windows **설정 → 앱 → 설치된 앱**에서 각 프로그램을 찾을 수 있습니다. 제거하면 해당 역할의 설정·등록·자동 실행도 제거하고 받은 파일은 유지합니다.


## v0.1.6 화면·파일·잠금

- **전체 화면**: PC 탭의 버튼을 누릅니다. 상단 복귀 버튼 또는 F11로 돌아갑니다.
- **Windows 키**: 원격 입력을 켜고 원격 화면을 클릭하세요. 원격 화면에 초점이 있을 때 Windows 키·조합키가 대상에 전달됩니다. 다른 앱으로 초점을 옮기면 로컬 입력으로 돌아갑니다.
- **파일 보내기**: 파일을 선택하고 대상 폴더 경로를 입력합니다. 대상에서 저장 위치를 확인·선택하면 그 폴더에 저장됩니다. 경로를 비우면 대상에서 직접 폴더를 고릅니다. 기존 파일을 덮어쓰지 않도록 파일명에 전송 ID가 붙습니다.
- **② 과제 제출 요청**: 관리자 PC에 저장할 폴더를 먼저 고릅니다. 대상이 보낼 파일을 직접 선택하면 그 폴더로 복사합니다.
- **화면 잠금 ON/OFF**: 대상의 모든 일반 데스크톱 화면을 가리고 마우스·키보드를 잠급니다. 잠금 중 원격 화면도 검게 표시됩니다. Windows 보안 화면까지 차단하는 잠금은 아닙니다.
- **입력 잠금 ON/OFF**: 잠금 메뉴에서 마우스·키보드를 각각 선택해 적용합니다. 0초 설정은 연결 중 ON/OFF를 뜻합니다. 기존 클라이언트가 보낸 양수 시간 설정은 이전처럼 제한 시간이 적용됩니다.
- **내 화면 공유 → 일반 창으로 공유**: 대상은 공유 화면을 창으로 보고 다른 작업도 할 수 있습니다.
- **내 화면 공유 → 집중 모드로 공유**: 기본 모니터에는 관리자 화면을 크게 띄우고, 나머지 모니터는 가립니다. 대상의 일반 마우스·키보드 입력을 제한합니다. **공유 종료** 또는 긴급 해제·연결 종료 시 복원됩니다.
- 양방향 공유는 기본 모니터를 캡처하며 마우스 커서를 포함합니다. 렉 개선 정도는 노트북 성능과 네트워크에 따라 달라 실제 두 노트북에서 확인하세요.
- 종료·재시작 요청에는 60초 대기가 없습니다. 강제 종료 옵션은 사용하지 않으므로 Windows가 저장되지 않은 작업 등에 대한 확인을 표시할 수 있습니다.
- 최초 등록 허용, 대상의 프로그램 종료와 Ctrl+Alt+F12 긴급 해제는 유지합니다. 연결 확인이 15초 동안 오지 않으면 잠금·공유를 종료합니다.

### 영문 입력·대상 입력 차단·수신 위치

- 영문·숫자·기호는 문자로 전달해 대상 PC의 한/영 상태와 관계없이 입력합니다. 원격 입력을 켜고 대상의 입력 칸을 클릭하세요. 대상의 한글 IME를 사용할 때는 **더 보기 → 영문·문자 직접 입력**을 끄세요. Ctrl/Alt 단축키와 이동 키는 키 입력으로 전달됩니다.
- **원격 입력 중 대상 입력 차단**을 선택하면 원격 입력이 켜진 동안 대상의 물리 마우스·키보드를 차단합니다. 선택하지 않으면 함께 조작할 수 있습니다. 원격 입력을 끄면 이 옵션의 차단만 풀리고, 별도로 설정한 잠금은 유지됩니다. 긴급 해제와 연결 종료 시에는 모두 해제됩니다.
- **① 저장 폴더 선택**에서 PC별 수신 폴더를 지정하세요. 다음 연결에서도 유지되고, 대상이 직접 제출한 파일과 파일 받기 요청으로 선택한 파일 모두 이 폴더에 복사됩니다. 파일 받기 요청에서 새 폴더를 고르면 이후 제출 파일에도 적용됩니다. 저장 위치를 지정하지 않으면 기존 Downloads 아래 받은 파일 폴더를 사용합니다.

## v0.1.9 종료 승인·화면 선택

관리 대상의 **프로그램 종료**를 누르면 연결된 관리자에게 종료 승인 창이 표시됩니다. **종료 승인**을 선택하면 대상 프로그램이 종료되고, **거절**하거나 응답하지 않으면 계속 실행됩니다. 연결된 관리자가 없으면 로컬에서 종료할 수 있습니다. Windows 종료·로그아웃 및 긴급 해제는 승인 대상이 아닙니다.

관리자는 **긴급 제어 중지** 또는 **모든 PC 긴급 제어 중지**를 눌러 연결과 원격 입력·공유·잠금을 해제할 수 있습니다. 대상의 Ctrl+Alt+F12 및 긴급 해제 메뉴도 계속 사용할 수 있습니다.

**내 화면 공유 → 공유할 화면 선택…**에서 미리보기와 모니터 이름·해상도를 확인하고 선택하세요. 일반 창/집중 모드 공유 시작 때에도 화면을 선택합니다. 공유 중 화면을 바꾸는 것도 가능하며, 특정 앱 창이나 영역 선택은 포함하지 않습니다.

## v0.1.10 설정 탭·긴급 해제 단축키·화면 멈춤 개선

관리 대상의 **설정 탭**에서 **긴급 제어 해제**를 실행하고 현재 단축키를 확인할 수 있습니다. 트레이 우클릭 메뉴에는 창 열기와 프로그램 종료만 있습니다. 트레이 아이콘을 두 번 클릭해 창을 열 수 있습니다.

단축키는 Ctrl·Alt·Shift 중 두 개 이상과 F1~F24, 영문 또는 숫자 키를 조합한 뒤 **단축키 저장**을 눌러 변경합니다. 기본은 Ctrl+Alt+F12이며 다음 실행에도 유지됩니다. 비우거나 비활성화할 수 없고, 물리 키보드에서 화면·입력 잠금 중에도 작동합니다. 긴급 해제 후 다시 연결하려면 대상의 연결 탭에서 연결 대기를 시작하세요.

일반 **프로그램 종료**는 관리자 연결 중에 승인을 요청합니다. 관리자가 연결되어 있지 않으면 로컬 종료가 가능합니다. 긴급 해제와 Windows 종료·로그아웃은 관리자 승인을 기다리지 않습니다.

화면 캡처와 수신 이미지 변환을 백그라운드로 이동했습니다. 늦은 프레임 확인 응답을 구분하고 손상된 이미지 뒤에도 다음 프레임을 수신합니다. 관리자 화면 공유에서 확인 응답이 누락되면 2초 후 다시 전송합니다. 실제 전송 속도는 PC 성능과 네트워크 상태에 따라 달라집니다. 양쪽을 v0.1.10으로 업데이트하세요.

## v0.1.11 파일·과제 제출·알림

관리자에서 대상 PC를 연결한 뒤 화면 위의 버튼을 순서대로 사용하세요.

1. **① 저장 폴더 선택**: 폴더 선택 창에서 받은 파일을 저장할 위치를 고릅니다. 선택한 위치는 다음 연결에도 유지됩니다. 아래 ‘저장 위치’ 표시로 확인하세요.
2. **② 과제 제출 요청**: 과제 이름, 제한 시간(1~180분), 최대 파일 개수(1~50개)를 정하고 **제출 요청 보내기**를 누릅니다.
3. 대상에 항상 위에 뜨는 제출 창에서 **제출할 파일 선택**으로 파일을 고르고 **제출**을 누릅니다. 남은 시간과 선택 개수가 표시됩니다. 제한 시간 안에 제출을 시작하면 전송이 끝날 때까지 기다립니다. 모든 파일의 저장 완료가 확인되면 창이 닫힙니다.
4. 관리자에 제출 현황이 표시됩니다. **③ 받은 폴더 열기**로 결과를 확인하세요. 선택한 폴더 안에 PC별·과제별로 나누어 저장합니다. 시간 종료 전에 제출하지 않으면 제출 창이 닫히며, 연결 종료 때도 창을 정리합니다.

파일당 최대 크기는 256MB입니다. 대상에서 직접 선택한 파일만 제출됩니다. 제출 창이 열리면 파일 선택을 할 수 있도록 기존 화면·입력 잠금과 집중 모드가 풀립니다.

**파일 보내기**는 관리자에서 보낼 파일을 선택하고, 대상에 뜨는 폴더 선택 창에서 저장 위치를 고릅니다. 저장 경로를 직접 입력하는 단계는 없습니다. 양쪽 PC 모두 파일 저장 완료 시 알림 창과 Windows 알림음이 나옵니다. 알림 창의 **저장 폴더 열기**로도 파일 위치를 확인할 수 있습니다.

대상 **설정 탭**에서 **Windows 로그인 시 자동 실행**이 체크되어 있으면 자동 실행이 등록된 상태입니다. 체크하거나 해제하여 변경하세요. 집중 모드로 관리자 화면을 공유하는 동안 대상의 로컬 커서는 숨겨지고, 공유 종료·연결 종료·긴급 해제 후 복원됩니다. 공유 화면 안에 포함된 관리자 커서는 그대로 표시됩니다.

## 메시지 팝업 (v0.1.12)

관리자가 보낸 메시지는 대상 본창 대신 별도 팝업으로 뜹니다. 본창의 숨김·최소화 상태는 유지됩니다. **확인** 또는 닫기 버튼으로 팝업을 닫으세요. 추가 메시지는 같은 팝업에 이어서 표시되며, 읽는 동안에도 원격 연결과 화면 전송은 계속됩니다.
