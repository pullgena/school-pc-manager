# 실제 Windows PC 2대에서 확인할 항목

CI가 수행하는 검증과 별도로 물리 키보드·마우스, 방화벽, 원격 화면 동작은 실제 기기에서 확인합니다.

1. 같은 사설망의 관리자·대상에서 두 EXE 실행 → 등록 파일 전달 → 연결 승인.
2. 잘못된 등록 키와 인증서 지문으로 연결 거절 확인.
3. 기본 모니터 화면, 좌우 여백이 있는 화면, Windows 배율 100%/150%에서 포인터 위치 확인.
4. 마우스 이동·좌우 클릭·휠, 영문·한글 IME·화살표·Tab 입력 확인.
5. Alt/Shift/마우스 버튼을 누른 채 원격 화면에서 다른 버튼으로 이동 → 입력 해제 확인.
6. 마우스만/키보드만/동시 잠금 → 원격 입력 유지 및 제한 시간 자동 해제 확인.
7. 잠금 중 대상에서 Ctrl+Alt+F12 → 입력 복구·현재 연결 종료 확인.
8. 잠금 중 LAN 케이블 분리/관리자 강제 종료 → 15초 이내 입력 복구 확인.
9. Windows 잠금 → 직접 로그인만 가능, 보안 화면 원격 입력 불가 확인.
10. 양방향 0바이트·한글 파일명·256MB 이하 파일 전송 → 해시와 저장 위치 확인.
11. 전송 중 끊김 → `.part` 제거, 완료된 기존 파일 유지 확인.
12. 2대 이상 대상 연결, 탭 전환, 전체 해제 확인.
13. 새 정식 릴리스 설치 → 버전 증가·설정 유지·이전 파일 백업 확인.
14. 파일 교체 권한 없는 폴더에서 업데이트 실패 메시지 확인.
15. PC 재시작·종료 요청 거절 및 승인 후 60초 유예 확인.

Windows 10은 에디션 및 ESU/LTSC 적용 여부에 따라 OS 지원 상태가 다르므로 학교 운영 환경을 확인합니다.
권장 운영 환경은 지원 중인 Windows 11 x64입니다.

16. 목록 클릭 연결·중복 클릭·끊어진 탭 재연결·전체 종료 확인.
17. 테스트용 Wi-Fi 프로필을 선택해 삭제하고 다른 프로필 유지 확인 (학교 정책 프로필 제외).
18. Wi-Fi 연결 해제 시 원격 연결 종료와 입력 잠금 복구 확인.
19. 임시 폴더에 둔 EXE에서 현재 프로그램 제거 → 해당 역할 EXE/설정 제거, 다른 역할과 받은 파일 유지 확인.


## v0.1.5 현장 확인 (아직 실행하지 않은 항목)

- 두 노트북에 각 역할의 Setup EXE로 설치하고 시작 메뉴에서 실행합니다.
- 대상의 첫 승인에서 자동 허용을 선택한 후 재접속 시 승인 창이 생략되는지 확인합니다.
- 대상 창을 X로 닫아도 트레이 아이콘과 원격 연결이 유지되는지 확인합니다.
- Ctrl+Alt+F12로 해제한 뒤 관리자가 재접속하지 못하는지 확인합니다. 대상에서 연결 대기를 재시작하면 다시 연결되어야 합니다.
- 대상 Windows 계정을 로그아웃·로그인하여 트레이 실행과 연결 대기를 확인합니다. 로그인 전 제어는 지원하지 않습니다.
- 새 버전 업데이트 뒤 설치 폴더의 EXE.previous가 직전 EXE와 일치하는지 확인합니다.
- Windows 앱 목록에서 제거하고 트레이·바로가기·자동 실행 등록이 사라지는지 확인합니다. 받은 파일은 유지되어야 합니다.
