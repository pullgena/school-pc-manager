# School PC Manager

Windows 관리자 프로그램과 관리 대상 프로그램으로 구성된 교실 PC 관리 도구입니다.
`here.txt`는 저장소 표시 파일로 확인했으며 원본을 유지합니다.

## 다운로드

[최신 릴리스](https://github.com/pullgena/school-pc-manager/releases/latest)에서 아래 파일을 받으세요.

| 파일 | 실행할 컴퓨터 |
|---|---|
| `SchoolPc.Admin.exe` | 관리자 PC |
| `SchoolPc.Agent.exe` | 관리할 각 PC |
| `SchoolPc-Windows-x64.zip` | 두 EXE와 사용 안내를 함께 받는 압축 파일 |

.NET 런타임을 포함한 단일 EXE입니다. 별도 Python, Node.js, .NET 설치가 필요 없습니다.
실행 파일은 본인에게 쓰기 권한이 있는 폴더에 두세요. 업데이트 시 해당 파일을 교체합니다.
초기 실행 파일에는 상용 코드 서명이 없으므로 Windows가 게시자를 확인할 수 없다는 알림을 표시할 수 있습니다.

## 기능

- 여러 PC 등록·동시 연결, PC별 탭
- 목록 클릭 연결, 전체 연결/전체 종료, 끊어진 탭 원클릭 재연결
- PC 등록 삭제, Windows Wi-Fi 저장 정보 삭제·연결 해제, 현재 프로그램 제거
- 기본 모니터 화면 공유 (최대 너비 1600px, JPEG, 약 3FPS)
- 원격 마우스 이동·클릭·휠, 가상 키 기반 키보드 제어
- 양방향 파일 전송 (최대 파일 256MB, 64KB 조각, SHA-256 검증)
- 마우스·키보드 개별 잠금, 1~120초 자동 해제
- Windows 잠금, 현장 승인 후 다시 시작·종료 요청
- 관리자 메시지 전달, 모든 PC 입력 잠금 해제
- TLS 1.2/1.3, 인증서 SHA-256 고정, 무작위 256비트 등록 키
- 현장 연결 승인·연결 표시, Ctrl+Alt+F12 긴급 종료
- GitHub Releases 업데이트 확인, GitHub 제공 SHA-256 검증, 자동 교체·재시작

## 빠른 시작

1. 대상 PC에서 `SchoolPc.Agent.exe`를 실행합니다.
2. PC 이름과 연결 주소를 확인하고 **관리자 등록 파일 저장**으로 JSON을 저장합니다.
3. 대상 PC에서 **연결 대기 시작**을 누릅니다. 방화벽 알림은 학교의 사설 네트워크에서 허용하세요.
4. 등록 JSON을 관리자에게 전달합니다. 관리자 프로그램에서 **등록 파일 가져오기**를 누릅니다.
5. PC를 선택하고 **선택한 PC 연결**을 누른 뒤 대상 PC에서 **이 연결 허용**을 누릅니다.
6. 해당 PC 탭에서 **화면 보기**를 켭니다. 조작하려면 **원격 입력**을 켜고 원격 화면을 클릭합니다.

자세한 화면별 설명은 [사용방법](docs/사용방법.md)에 있습니다.
등록 JSON에는 접근 키가 들어 있습니다. 공개 저장소에 올리지 말고, 전달 후 사본은 지우세요.
저장된 인증 정보는 Windows DPAPI로 현재 Windows 사용자 계정에 묶어 암호화합니다.

## 연결과 잠금 동작

- 초기 버전은 같은 네트워크에서 대상 주소에 직접 연결하는 방식입니다. 기본 TCP 포트: `45832`.
- 인터넷 중계 서버, NAT 통과, 자동 네트워크 검색은 포함하지 않습니다.
- 대상이 먼저 실행되어 대기해야 합니다. Windows 서비스·자동 시작·숨김 실행은 등록하지 않습니다.
- 인증된 관리자 1명이 PC 1대에 연결할 수 있습니다. 접속마다 대상 PC에서 승인을 받습니다.
- 2초마다 연결 상태를 확인하고 15초 응답이 없으면 연결을 종료해 입력 잠금을 풉니다.
- 입력 잠금은 최대 120초입니다. **잠금 적용**을 다시 눌러 새 시간을 설정할 수 있습니다.
- **Ctrl+Alt+F12**는 대상의 물리 키보드에서 현재 제어 연결을 끊고 모든 입력 잠금을 해제합니다.
- Windows의 **Ctrl+Alt+Del** 보안 화면은 차단하지 않습니다.
- **Windows 잠금**을 풀려면 대상 PC에서 직접 로그인해야 합니다. 원격 로그인/UAC 보안 화면 제어는 지원하지 않습니다.
- 다시 시작·종료는 대상에서 별도 승인해야 실행되며 60초 후 실행됩니다.
- 일반 사용자 권한으로 실행합니다. 관리자 권한 창에 입력하는 것은 Windows의 권한 경계에 따라 제한됩니다.
- 한글 입력은 대상 PC의 IME 상태를 따릅니다. 다중 모니터·고속 영상·게임·단축키 일부는 이 초기 버전의 범위에 포함하지 않습니다.

## GitHub 빌드와 릴리스

2026년 기준 LTS인 .NET 10과 Windows Forms를 사용합니다.

- `main` 푸시/PR: 테스트, Windows UI 초기화 검증, 두 EXE 빌드, Actions Artifact 저장.
- `Directory.Build.props`의 버전을 올린 후 main 빌드가 성공하면, 해당 버전 릴리스가 없을 때 새 정식 릴리스를 만들고 파일을 올립니다.
- 이후: `v0.1.1`처럼 새 태그의 정식 Release를 게시하거나 **Actions → Build and release Windows apps → Run workflow**에서 `version` 입력과 `publish` 체크를 사용합니다.
- 새 버전의 `SchoolPc.Admin.exe`, `SchoolPc.Agent.exe`를 릴리스에 첨부하면 각 프로그램의 **업데이트 확인**으로 설치할 수 있습니다.
- 기존 버전의 실행 파일을 덮어쓰지 않습니다. 업데이트를 배포할 때에는 새 버전 번호를 사용하세요.
- 게시된 릴리스에서 빌드할 때 릴리스 태그를 체크아웃합니다. 릴리스 태그가 실제 새 소스를 가리키는지 확인하세요.
- GitHub Actions에 `contents: write`를 선언합니다. 학교/조직의 정책에서 쓰기를 막은 경우 자동 릴리스 게시가 실패할 수 있습니다.

업데이트는 공개 저장소의 최신 **정식** 릴리스를 확인합니다. GitHub가 파일의 `sha256:` digest를 제공할 때만 설치합니다.
소스 전체에 접근 키나 GitHub 개인 토큰을 넣지 않습니다. CI는 기본 `GITHUB_TOKEN`으로 배포합니다.

## 개발·검증

Windows 11 x64와 .NET 10 SDK에서:

```powershell
dotnet run --project tests/SchoolPc.Tests -c Release
dotnet run --project tests/SchoolPc.WindowsSmoke -c Release
dotnet run --project src/SchoolPc.Agent
dotnet run --project src/SchoolPc.Admin
```

프로토콜 테스트는 패킷 크기 제한·동시 전송·파일 경로 탈출·조각 순서·해시·인증 키·업데이트 주소·실제 TLS 인증서 검증을 확인합니다.
Windows 테스트는 DPAPI, 입력 훅 생명주기, 관리자/대상 창 초기화를 확인합니다.
[현장 확인 목록](docs/현장확인.md)의 실제 두 PC 테스트도 진행한 뒤 학교 전체에 배포하세요.

## 소스 구성

| 폴더 | 역할 |
|---|---|
| `src/SchoolPc.Core` | 통신 프로토콜, 등록 정보 검증, 파일 전송, 릴리스 검증 |
| `src/SchoolPc.Windows` | Win32 입력 제어, UI 공통, DPAPI, 업데이트 도우미 |
| `src/SchoolPc.Agent` | 대상 창, TLS 서버, 연결 승인, 화면 캡처 |
| `src/SchoolPc.Admin` | PC 등록, 다중 연결 탭, 원격 화면 입력 |
| `tests` | 프로토콜/TLS/파일 검증 및 Windows 초기화 검사 |

## 0.1.1 연결·삭제 기능

- **한 번에 모두 연결**: 저장한 등록 정보로 모든 PC에 연결합니다. 최초 등록 파일 가져오기와 대상의 접속 승인은 유지합니다.
- **목록 클릭으로 바로 연결**: 체크하면 PC 목록을 한 번 클릭할 때 연결합니다. 이미 연결된 PC는 해당 탭을 열고, 종료된 탭은 새 연결로 바꿉니다.
- **모든 연결 종료**: 모든 원격 제어 연결을 끊습니다. Windows 인터넷 연결 자체를 끊는 기능과 구분합니다.
- **PC 등록 삭제**: 선택한 PC의 연결을 끝내고 관리자에 저장된 등록과 연결 키를 지웁니다.
- **Windows Wi-Fi 관리**: 이 PC의 Wi-Fi 어댑터 연결 해제, 선택한 저장 Wi-Fi 정보 삭제, Windows 인터넷 설정 열기. 학교 정책 프로필은 삭제하지 않습니다.
- **대상 Wi-Fi 관리 요청**: 대상 PC에 관리 창을 엽니다. 대상 창에서 삭제할 Wi-Fi를 선택하고 확인합니다. 대상의 입력 잠금은 해제합니다.
- **현재 프로그램 제거**: 실행 중인 역할의 EXE, 등록/인증 설정, 로그, 이전 버전 백업을 제거합니다. 다른 역할의 EXE, 받은 파일, Wi-Fi 프로필, 다운로드 ZIP과 전달용 등록 파일은 지우지 않습니다. 임시 도우미 사본은 완료 안내에서 알려 주며 별도로 지울 수 있습니다.

Wi-Fi 기능은 Windows WLAN API를 사용하며 저장된 Wi-Fi 비밀번호를 읽거나 표시하지 않습니다.
Wi-Fi 정책/권한에 따라 삭제가 제한될 수 있으며, Wi-Fi 연결을 끊으면 현재 원격 연결도 종료될 수 있습니다.
현재 프로그램 제거는 릴리스 EXE로 실행한 경우 사용할 수 있습니다.
