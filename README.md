# School PC Manager

Windows 관리자 프로그램과 관리 대상 프로그램으로 구성된 교실 PC 관리 도구입니다.
`here.txt`는 저장소 표시 파일로 확인했으며 원본을 유지합니다.

## 다운로드

[최신 릴리스](https://github.com/pullgena/school-pc-manager/releases/latest)에서 아래 파일을 받으세요.

| 파일 | 실행할 컴퓨터 |
|---|---|
| `SchoolPc.Admin.Setup.exe` | 관리자 PC에 설치 |
| `SchoolPc.Admin.exe` | 관리자용 휴대 실행 파일 |
| `SchoolPc.Agent.Setup.exe` | 관리할 각 PC에 설치 |
| `SchoolPc.Agent.exe` | 대상용 휴대 실행 파일 |
| `SchoolPc-Windows-x64.zip` | 설치 프로그램·휴대 실행 파일·사용 안내 압축 파일 |

.NET 런타임을 포함한 단일 EXE입니다. 별도 Python, Node.js, .NET 설치가 필요 없습니다.
실행 파일은 본인에게 쓰기 권한이 있는 폴더에 두세요. 업데이트 시 해당 파일을 교체합니다.
초기 실행 파일에는 상용 코드 서명이 없으므로 Windows가 게시자를 확인할 수 없다는 알림을 표시할 수 있습니다.

## 기능

- 여러 PC 등록·동시 연결, PC별 탭
- 목록 클릭 연결, 전체 연결/전체 종료, 끊어진 탭 원클릭 재연결
- PC 등록 삭제, Windows Wi-Fi 저장 정보 삭제·연결 해제, 현재 프로그램 제거
- 기본 모니터 화면 공유 (최대 너비 1600px, JPEG, 약 3FPS)
- 원격 마우스 이동·클릭·휠, 가상 키 기반 키보드 제어
- 양방향 파일 전송 (최대 파일 256MB, 64KB 조각, SHA-256 검증)
- 마우스·키보드 개별 잠금, 연결 중 ON/OFF
- Windows 잠금, 현장 승인 후 다시 시작·종료 요청
- 관리자 메시지 전달, 모든 PC 입력 잠금 해제
- TLS 1.2/1.3, 인증서 SHA-256 고정, 무작위 256비트 등록 키
- 현장 연결 승인·연결 표시, Ctrl+Alt+F12 긴급 종료
- GitHub Releases 업데이트 확인, GitHub 제공 SHA-256 검증, 자동 교체·재시작

## 빠른 시작

1. 대상 PC에서 `SchoolPc.Agent.exe`를 실행합니다.
2. PC 이름과 연결 주소를 확인하고 **관리자 등록 파일 저장**으로 JSON을 저장합니다.
3. 대상 PC에서 **연결 대기 시작**을 누릅니다. 방화벽 알림은 학교의 사설 네트워크에서 허용하세요.
4. 등록 JSON을 관리자에게 전달합니다. 관리자 프로그램에서 **PC 추가**를 누릅니다.
5. PC를 선택하고 **선택한 PC 연결**을 누른 뒤 대상 PC에서 **이 연결 허용**을 누릅니다.
6. 승인이 끝나면 해당 PC 탭에 화면이 자동 표시됩니다. 조작하려면 **원격 입력**을 켜고 원격 화면을 클릭합니다.

자세한 화면별 설명은 [사용방법](docs/사용방법.md)에 있습니다.
등록 JSON에는 접근 키가 들어 있습니다. 공개 저장소에 올리지 말고, 전달 후 사본은 지우세요.
저장된 인증 정보는 Windows DPAPI로 현재 Windows 사용자 계정에 묶어 암호화합니다.

## 연결과 잠금 동작

- 초기 버전은 같은 네트워크에서 대상 주소에 직접 연결하는 방식입니다. 기본 TCP 포트: `45832`.
- 인터넷 중계 서버, NAT 통과, 자동 네트워크 검색은 포함하지 않습니다.
- 대상이 먼저 실행되어 대기해야 합니다. Windows 서비스·자동 시작·숨김 실행은 등록하지 않습니다.
- 인증된 관리자 1명이 PC 1대에 연결할 수 있습니다. 최초 승인 후 등록 관리자 자동 허용을 선택하면 이후 승인을 생략합니다.
- 2초마다 연결 상태를 확인하고 15초 응답이 없으면 연결을 종료해 입력 잠금을 풉니다.
- 입력 잠금은 연결 중 ON/OFF로 제어합니다. 긴급 해제와 연결 종료 시 풀립니다.
- **Ctrl+Alt+F12**는 대상의 물리 키보드에서 현재 제어 연결을 끊고 모든 입력 잠금을 해제합니다.
- Windows의 **Ctrl+Alt+Del** 보안 화면은 차단하지 않습니다.
- **Windows 잠금**을 풀려면 대상 PC에서 직접 로그인해야 합니다. 원격 로그인/UAC 보안 화면 제어는 지원하지 않습니다.
- 다시 시작·종료는 자동 허용 상태이면 추가 승인 없이, 그렇지 않으면 대상 승인 후 즉시 실행됩니다.
- 일반 사용자 권한으로 실행합니다. 관리자 권한 창에 입력하는 것은 Windows의 권한 경계에 따라 제한됩니다.
- 한글 입력은 대상 PC의 IME 상태를 따릅니다. 다중 모니터·고속 영상·게임·단축키 일부는 이 초기 버전의 범위에 포함하지 않습니다.

## GitHub 빌드와 릴리스

2026년 기준 LTS인 .NET 10과 Windows Forms를 사용합니다.

- `main` 푸시/PR: 테스트, Windows UI 초기화 검증, 두 EXE 빌드, Actions Artifact 저장.
- `Directory.Build.props`의 버전을 올린 후 main 빌드가 성공하면, 해당 버전 릴리스가 없을 때 새 정식 릴리스를 만들고 파일을 올립니다.
- 이후: `v0.1.1`처럼 새 태그의 정식 Release를 게시하거나 **Actions → Build and release Windows apps → Run workflow**에서 `version` 입력과 `publish` 체크를 사용합니다.
- 새 버전의 `SchoolPc.Admin.exe`, `SchoolPc.Agent.exe`를 릴리스에 첨부하면 각 프로그램의 **업데이트 확인**으로 설치할 수 있습니다.
- 기존 버전의 실행 파일을 덮어쓰지 않습니다. 업데이트를 배포할 때에는 새 버전 번호를 사용하세요.
- 게시된 릴리스에서 빌드할 때 릴리스 태그를 체크아웃합니다. 릴리스 태그가 실제 새 소스를 가리키는지 확인하세요.
- GitHub Actions에 `contents: write`를 선언합니다. 학교/조직의 정책에서 쓰기를 막은 경우 자동 릴리스 게시가 실패할 수 있습니다.

업데이트는 공개 저장소의 최신 **정식** 릴리스를 확인합니다. GitHub가 파일의 `sha256:` digest를 제공할 때만 설치합니다.
소스 전체에 접근 키나 GitHub 개인 토큰을 넣지 않습니다. CI는 기본 `GITHUB_TOKEN`으로 배포합니다.

## 개발·검증

Windows 11 x64와 .NET 10 SDK에서:

```powershell
dotnet run --project tests/SchoolPc.Tests -c Release
dotnet run --project tests/SchoolPc.WindowsSmoke -c Release
dotnet run --project src/SchoolPc.Agent
dotnet run --project src/SchoolPc.Admin
```

프로토콜 테스트는 패킷 크기 제한·동시 전송·파일 경로 탈출·조각 순서·해시·인증 키·업데이트 주소·실제 TLS 인증서 검증을 확인합니다.
Windows 테스트는 DPAPI, 입력 훅 생명주기, 관리자/대상 창 초기화를 확인합니다.
[현장 확인 목록](docs/현장확인.md)의 실제 두 PC 테스트도 진행한 뒤 학교 전체에 배포하세요.

## 0.1.1 연결·삭제 기능

- **모두 연결**: 저장한 등록 정보로 모든 PC에 연결합니다. 최초 등록 파일 가져오기와 대상의 접속 승인은 유지합니다.
- **목록 클릭으로 바로 연결**: 체크하면 PC 목록을 한 번 클릭할 때 연결합니다. 이미 연결된 PC는 해당 탭을 열고, 종료된 탭은 새 연결로 바꿉니다.
- **모두 연결 끊기**: 모든 원격 제어 연결을 끊습니다. Windows 인터넷 연결 자체를 끊는 기능과 구분합니다.
- **PC 등록 삭제**: 선택한 PC의 연결을 끝내고 관리자에 저장된 등록과 연결 키를 지웁니다.
- **Windows Wi-Fi 관리**: 이 PC의 Wi-Fi 어댑터 연결 해제, 선택한 저장 Wi-Fi 정보 삭제, Windows 인터넷 설정 열기. 학교 정책 프로필은 삭제하지 않습니다.
- **대상 Wi-Fi 관리 요청**: 대상 PC에 관리 창을 엽니다. 대상 창에서 삭제할 Wi-Fi를 선택하고 확인합니다. 대상의 입력 잠금은 해제합니다.
- **현재 프로그램 제거**: 실행 중인 역할의 EXE, 등록/인증 설정, 로그, 이전 버전 백업을 제거합니다. 다른 역할의 EXE, 받은 파일, Wi-Fi 프로필, 다운로드 ZIP과 전달용 등록 파일은 지우지 않습니다. 임시 도우미 사본은 완료 안내에서 알려 주며 별도로 지울 수 있습니다.

Wi-Fi 기능은 Windows WLAN API를 사용하며 저장된 Wi-Fi 비밀번호를 읽거나 표시하지 않습니다.
Wi-Fi 정책/권한에 따라 삭제가 제한될 수 있으며, Wi-Fi 연결을 끊으면 현재 원격 연결도 종료될 수 있습니다.
현재 프로그램 제거는 릴리스 EXE로 실행한 경우 사용할 수 있습니다.

## v0.1.2 간단한 UI

첫 화면에는 연결에 필요한 기능만 표시합니다. 관리자: PC 목록·PC 추가·모두 연결·모두 연결 끊기. 대상: 연결 대기 시작·종료·등록 파일 저장.
파일은 **파일**, 입력 잠금은 **잠금**, 메시지·전원·대상 Wi-Fi는 **더 보기**, 내 Wi-Fi·업데이트·제거는 **설정** 메뉴에 있습니다.
연결 후 화면 공유는 자동으로 시작하며 원격 입력은 직접 켜야 합니다.

## v0.1.3 노트북 전원

- **켜기**: 관리자 목록에서 PC를 선택 → **PC 설정 → 전원 켜기 (WOL)**. 연결되어 있지 않아도 저장된 MAC 주소로 로컬 네트워크에 신호를 보냅니다. 신호 전송 성공을 실제 켜짐 성공으로 표시하지 않습니다.
- **끄기·재시작**: 연결된 PC의 탭 → **전원 → 전원 끄기 / 재시작**. 자동 허용 상태이면 추가 승인 없이 즉시 실행합니다. 그 외에는 대상 승인 후 실행합니다.
- 새 대상 프로그램에서 등록 파일을 다시 저장하면 연결 주소와 일치하는 네트워크 어댑터의 MAC을 포함합니다. 이전 등록 파일에는 MAC이 없으므로 **PC 설정 → 주소·포트·MAC 변경**에서 직접 입력할 수도 있습니다.
- 꺼진 노트북을 켜려면 해당 모델의 BIOS/UEFI와 네트워크 장치가 WOL 및 해당 전원 상태에서의 깨우기를 지원해야 합니다. 유선 LAN과 Wi-Fi의 지원은 다릅니다. 노트북 제조사의 안내를 확인하세요.
- 같은 로컬 네트워크에서 사용하며 인터넷 중계·라우터 포트 개방·BIOS/드라이버 자동 변경은 수행하지 않습니다. 전원 공급이 끊긴 기기는 켤 수 없습니다.
- 설치 시 자동 실행을 선택하면 Windows 로그인 후 대상 프로그램이 실행됩니다. Windows 자동 로그인 기능은 포함하지 않습니다.

참고: [Microsoft WOL 동작](https://learn.microsoft.com/en-us/troubleshoot/windows-client/deployment/wake-on-lan-feature), [시스템 전원 상태](https://learn.microsoft.com/en-us/windows/win32/power/system-power-states).


## v0.1.5 설치·트레이·자동 허용

- 관리자 노트북: `SchoolPc.Admin.Setup.exe`를 설치합니다.
- 관리 대상 노트북: `SchoolPc.Agent.Setup.exe`를 설치합니다. **Windows 로그인 시 자동 실행**은 기본 선택됩니다.
- 기본 설치 경로: `%LOCALAPPDATA%\Programs\SchoolPcManager\Admin` 또는 `Agent`. 각 역할의 설치 위치는 따로 선택할 수 있습니다.
- 기존 휴대용 EXE는 종료하고 설치 프로그램을 실행하세요. 같은 Windows 사용자이면 기존 PC 등록·설정은 유지됩니다. 두 사본을 동시에 실행하지 마세요.
- 대상 프로그램은 실행하면 연결 대기를 시작합니다. X 버튼과 최소화는 트레이로 숨깁니다. 숨겨도 연결은 유지됩니다.
- 트레이 아이콘을 두 번 클릭하면 창을 열 수 있습니다. 트레이 메뉴에서는 창 열기와 프로그램 종료를 선택합니다. 긴급 해제는 프로그램의 **설정 탭**에서 사용합니다.
- 첫 연결 승인에서 **이 등록 키를 가진 관리자의 다음 연결·전원 요청 자동 허용**을 체크하고 허용하세요. 이후 동일한 등록 키의 요청에는 승인 창이 없습니다.
- 대상 **설정 → 등록 관리자 자동 허용 설정**에서 처음부터 허용하거나 취소할 수 있습니다. 등록 파일·키는 신뢰하는 관리자에게만 전달하세요.
- 대상 **설정 탭 → Windows 로그인 시 자동 실행 체크박스**에서 자동 실행을 변경할 수 있습니다. 로그인 전 원격 제어는 지원하지 않습니다.
- **Ctrl+Alt+F12**는 현재 연결과 연결 대기를 종료합니다. 다시 사용하려면 대상에서 연결 대기를 시작하세요.
- **업데이트 확인**으로 업데이트하면 설치 경로의 `SchoolPc.Admin.exe.previous` / `SchoolPc.Agent.exe.previous`에 직전 EXE가 저장됩니다. 새 설치 프로그램으로 덮어 설치해도 같은 위치에 백업합니다.
- 시작 메뉴와 Windows **설정 → 앱 → 설치된 앱**에서 각 프로그램을 찾을 수 있습니다. 제거하면 해당 역할의 설정·등록·자동 실행도 제거하고 받은 파일은 유지합니다.


## v0.1.6 화면·파일·잠금

- **전체 화면**: PC 탭의 버튼을 누릅니다. 상단 복귀 버튼 또는 F11로 돌아갑니다.
- **Windows 키**: 원격 입력을 켜고 원격 화면을 클릭하세요. 원격 화면에 초점이 있을 때 Windows 키·조합키가 대상에 전달됩니다. 다른 앱으로 초점을 옮기면 로컬 입력으로 돌아갑니다.
- **파일 보내기**: 파일을 선택하고 대상 폴더 경로를 입력합니다. 대상에서 저장 위치를 확인·선택하면 그 폴더에 저장됩니다. 경로를 비우면 대상에서 직접 폴더를 고릅니다. 기존 파일을 덮어쓰지 않도록 파일명에 전송 ID가 붙습니다.
- **② 과제 제출 요청**: 관리자 PC에 저장할 폴더를 먼저 고릅니다. 대상이 보낼 파일을 직접 선택하면 그 폴더로 복사합니다.
- **화면 잠금 ON/OFF**: 대상의 모든 일반 데스크톱 화면을 가리고 마우스·키보드를 잠급니다. 잠금 중 원격 화면도 검게 표시됩니다. Windows 보안 화면까지 차단하는 잠금은 아닙니다.
- **입력 잠금 ON/OFF**: 잠금 메뉴에서 마우스·키보드를 각각 선택해 적용합니다. 0초 설정은 연결 중 ON/OFF를 뜻합니다. 기존 클라이언트가 보낸 양수 시간 설정은 이전처럼 제한 시간이 적용됩니다.
- **내 화면 공유 → 일반 창으로 공유**: 대상은 공유 화면을 창으로 보고 다른 작업도 할 수 있습니다.
- **내 화면 공유 → 집중 모드로 공유**: 기본 모니터에는 관리자 화면을 크게 띄우고, 나머지 모니터는 가립니다. 대상의 일반 마우스·키보드 입력을 제한합니다. **공유 종료** 또는 긴급 해제·연결 종료 시 복원됩니다.
- 양방향 공유는 기본 모니터를 캡처하며 마우스 커서를 포함합니다. 렉 개선 정도는 노트북 성능과 네트워크에 따라 달라 실제 두 노트북에서 확인하세요.
- 종료·재시작 요청에는 60초 대기가 없습니다. 강제 종료 옵션은 사용하지 않으므로 Windows가 저장되지 않은 작업 등에 대한 확인을 표시할 수 있습니다.
- 최초 등록 허용, 대상의 프로그램 종료와 Ctrl+Alt+F12 긴급 해제는 유지합니다. 연결 확인이 15초 동안 오지 않으면 잠금·공유를 종료합니다.

## v0.1.10 설정 탭·긴급 해제 단축키·화면 멈춤 개선

관리 대상의 **설정 탭**에서 **긴급 제어 해제**를 실행하고 현재 단축키를 확인할 수 있습니다. 트레이 우클릭 메뉴에는 창 열기와 프로그램 종료만 있습니다. 트레이 아이콘을 두 번 클릭해 창을 열 수 있습니다.

단축키는 Ctrl·Alt·Shift 중 두 개 이상과 F1~F24, 영문 또는 숫자 키를 조합한 뒤 **단축키 저장**을 눌러 변경합니다. 기본은 Ctrl+Alt+F12이며 다음 실행에도 유지됩니다. 비우거나 비활성화할 수 없고, 물리 키보드에서 화면·입력 잠금 중에도 작동합니다. 긴급 해제 후 다시 연결하려면 대상의 연결 탭에서 연결 대기를 시작하세요.

일반 **프로그램 종료**는 관리자 연결 중에 승인을 요청합니다. 관리자가 연결되어 있지 않으면 로컬 종료가 가능합니다. 긴급 해제와 Windows 종료·로그아웃은 관리자 승인을 기다리지 않습니다.

화면 캡처와 수신 이미지 변환을 백그라운드로 이동했습니다. 늦은 프레임 확인 응답을 구분하고 손상된 이미지 뒤에도 다음 프레임을 수신합니다. 관리자 화면 공유에서 확인 응답이 누락되면 2초 후 다시 전송합니다. 실제 전송 속도는 PC 성능과 네트워크 상태에 따라 달라집니다. 양쪽을 v0.1.10으로 업데이트하세요.

## v0.1.11 파일·과제 제출·알림

관리자에서 대상 PC를 연결한 뒤 화면 위의 버튼을 순서대로 사용하세요.

1. **① 저장 폴더 선택**: 폴더 선택 창에서 받은 파일을 저장할 위치를 고릅니다. 선택한 위치는 다음 연결에도 유지됩니다. 아래 ‘저장 위치’ 표시로 확인하세요.
2. **② 과제 제출 요청**: 과제 이름, 제한 시간(1~180분), 최대 파일 개수(1~50개)를 정하고 **제출 요청 보내기**를 누릅니다.
3. 대상에 항상 위에 뜨는 제출 창에서 **제출할 파일 선택**으로 파일을 고르고 **제출**을 누릅니다. 남은 시간과 선택 개수가 표시됩니다. 제한 시간 안에 제출을 시작하면 전송이 끝날 때까지 기다립니다. 모든 파일의 저장 완료가 확인되면 창이 닫힙니다.
4. 관리자에 제출 현황이 표시됩니다. **③ 받은 폴더 열기**로 결과를 확인하세요. 선택한 폴더 안에 PC별·과제별로 나누어 저장합니다. 시간 종료 전에 제출하지 않으면 제출 창이 닫히며, 연결 종료 때도 창을 정리합니다.

파일당 최대 크기는 256MB입니다. 대상에서 직접 선택한 파일만 제출됩니다. 제출 창이 열리면 파일 선택을 할 수 있도록 기존 화면·입력 잠금과 집중 모드가 풀립니다.

**파일 보내기**는 관리자에서 보낼 파일을 선택하고, 대상에 뜨는 폴더 선택 창에서 저장 위치를 고릅니다. 저장 경로를 직접 입력하는 단계는 없습니다. 양쪽 PC 모두 파일 저장 완료 시 알림 창과 Windows 알림음이 나옵니다. 알림 창의 **저장 폴더 열기**로도 파일 위치를 확인할 수 있습니다.

대상 **설정 탭**에서 **Windows 로그인 시 자동 실행**이 체크되어 있으면 자동 실행이 등록된 상태입니다. 체크하거나 해제하여 변경하세요. 집중 모드로 관리자 화면을 공유하는 동안 대상의 로컬 커서는 숨겨지고, 공유 종료·연결 종료·긴급 해제 후 복원됩니다. 공유 화면 안에 포함된 관리자 커서는 그대로 표시됩니다.

## v0.1.12 메시지 팝업

관리자 메시지는 대상 프로그램 본창 대신 별도 팝업으로 표시됩니다. 본창이 숨겨져 있거나 최소화되어 있어도 그 상태를 유지합니다. 팝업은 항상 위에 표시되며 **확인** 또는 닫기 버튼으로 닫을 수 있습니다. 열려 있는 동안 추가 메시지는 같은 팝업에 이어서 표시됩니다. 팝업을 읽거나 닫는 동안에도 원격 연결과 화면 전송은 계속됩니다.
